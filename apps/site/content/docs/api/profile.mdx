## GET /v1/profile

Returns the stored profile of a container and its newest current facts. It reads what's already there and never calls the LLM. The summaries are rebuilt in the background after facts change (see [profile](/docs/how-it-works#profile)).

| Name | Type | Required | Default | Limits |
|---|---|---|---|---|
| `container` | string | no | server default | 1 to 128 characters |
| `q` | string | no | | up to 2,000 characters. When set, adds `searchResults` |

```bash
curl "https://recall.zakiego.com/v1/profile?container=alice&q=shoes" \
  -H "Authorization: Bearer $RECALL_KEY"
```

- `static` and `dynamic` are empty strings until the first profile job has run, and `updatedAt` is `null`.
- `staticMemories` and `dynamicMemories` hold up to 25 current facts each, newest first.
- `searchResults` is only there when `q` is set. It holds up to 10 memory hits, with the same shape as [`POST /v1/search`](/docs/api/search).

| Status | When |
|---|---|
| `200` | The profile, possibly empty |
| `400` | `q` or `container` out of range |
