## GET /v1/containers

Lists every container in the workspace that has at least one document or current fact, most recently active first. No parameters.

```bash
curl https://recall.zakiego.com/v1/containers \
  -H "Authorization: Bearer $RECALL_KEY"
```

```json
{
  "containers": [
    {
      "container": "alice",
      "memories": 42,
      "documents": 17,
      "lastActivity": 1762675200000
    },
    {
      "container": "default",
      "memories": 3,
      "documents": 2,
      "lastActivity": 1762588800000
    }
  ]
}
```

| Field | Meaning |
|---|---|
| `container` | The container name |
| `memories` | Current facts (superseded and deleted ones don't count) |
| `documents` | Documents, in any status |
| `lastActivity` | The newest `createdAt` among its current facts and documents, in Unix milliseconds |

A container whose facts were all deleted and whose documents were all removed drops off the list.
